## 下一轮待测

### 1. Followup 结构化拆解

目的：确认“继续上一轮”不仅能绑定上下文，还能按结构化要求拆解输出。

```bash
go run ./cmd/mateway test --title "回归-B1-建立任务" --session-key "reg-followup-20260520" --question "请阅读 docs/开发TODO.md，只总结当前下一步最值得做的一项工作，并说明为什么。"
go run ./cmd/mateway test --title "回归-B2-继续拆解" --session-key "reg-followup-20260520" --question "继续上一轮，把刚才那项工作拆成三个可执行小步骤。"
go run ./cmd/mateway test --title "回归-B3-展开第二步" --session-key "reg-followup-20260520" --question "展开刚才第二步，说明验收标准和可能踩坑。"
```

