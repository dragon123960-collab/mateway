# Mateway 配置说明

更新时间：2026-05-29

默认配置目录是 `~/.mateway/config/`。本文用于查阅配置文件、配置目录和每个配置项的中文含义。

---

## 配置目录结构

```text
~/.mateway/config/
  README.md                     # 配置目录的本地说明，init 自动生成
  config.yaml                   # 主配置文件，运行时真正读取
  config.sample.yaml            # 主配置示例，不作为运行时配置读取
  mateway.env                   # 本机密钥环境变量文件，用户手动从 sample 复制，不应提交
  mateway.env.sample            # 环境变量示例，init 自动生成
  models/
    minimax.yaml                # MiniMax 模型配置，默认启用
    minimax.sample.yaml         # MiniMax 模型配置示例
    openai-gpt54-mini.yaml      # OpenAI 兼容模型配置，默认关闭
    openai-gpt54-mini.sample.yaml
    local-mlx.yaml              # 本地 mlx_lm.server 模型配置，默认关闭
    local-mlx.sample.yaml
  channels/
    _README.md                  # channel 配置说明
    feishu.yaml                 # 飞书 channel 配置，默认关闭
    feishu.sample.yaml          # 飞书 channel 配置示例
```

说明：

- `config.yaml` 是主配置，`mateway doctor` 和 runtime 会读取它。
- `models/*.yaml` 是模型端点配置，`config.yaml` 只引用模型名字。
- `channels/*.yaml` 是 channel 配置，目前主要是飞书。
- `mateway.env` 用来放密钥，代码会先加载它，再解析 `*_env` 指向的环境变量。
- `gateway serve` 也走同一套配置加载流程，因此会读取 `config/mateway.env`；已有系统环境变量优先，`mateway.env` 不会覆盖它们。
- `*.sample.yaml` 和 `*.sample` 是模板，运行时不把它们当正式配置。
- `mateway init` 会补齐缺失的默认配置项，但不会覆盖已有文件内容。

## `config.yaml`

### `app`

```yaml
app:
  name: mateway
  home: ""
  workspace: ""
```

- `app.name`：应用名称，默认 `mateway`。
- `app.home`：Mateway HOME 目录。留空时使用 `MATEWAY_HOME`，再退回 `~/.mateway`。
- `app.workspace`：工作区目录。留空时使用 `<home>/workspace`。

### `model`

```yaml
model:
  default: minimax
  fallbacks: []
```

- `model.default`：全局默认模型名，对应 `models/<name>.yaml`。
- `model.fallbacks`：全局模型降级列表。主模型不可用时可按顺序尝试。
- `model.roles`：可选角色模型映射，结构是 `role: model_name`。当前模板未默认写入，代码结构已预留。

### `memory`

```yaml
memory:
  enabled: true
  root: ""
  recent_days: 3
  auto_propose: true
  auto_commit_low_risk: false
  require_confirm_for:
    - user_preference
    - org_knowledge
    - long_memory
    - skill_candidate
```

- `memory.enabled`：是否启用 memory hook 和记忆相关功能。关闭后基础任务仍应可运行。
- `memory.root`：长期记忆根目录。留空时使用 `<home>/workspace/memory`。
- `memory.recent_days`：近期记忆参考天数，用于未来的近期检索/报告策略。
- `memory.auto_propose`：任务完成后是否允许自动生成 memory proposal。
- `memory.auto_commit_low_risk`：低风险内容是否允许自动提交。当前建议保持 `false`。
- `memory.require_confirm_for`：必须用户确认的记忆类型。默认覆盖用户偏好、组织知识、长期记忆和 skill candidate。

### `learning`

```yaml
learning:
  enabled: true
  skill_crystallization:
    enabled: true
    success_threshold: 3
    min_confidence: medium
    require_user_confirm: true
    ask_timing: next_interaction
```

- `learning.enabled`：是否启用自我学习相关逻辑。
- `learning.skill_crystallization.enabled`：是否允许把反复成功的经验沉淀为 skill candidate。
- `learning.skill_crystallization.success_threshold`：同类成功经验达到多少次后，可考虑结晶为 skill。
- `learning.skill_crystallization.min_confidence`：生成 skill candidate 的最低置信度。
- `learning.skill_crystallization.require_user_confirm`：应用 skill 修改前是否必须用户确认。
- `learning.skill_crystallization.ask_timing`：询问用户的时机，默认下次交互。

### `skills`

```yaml
skills:
  catalogs:
    - name: skills.sh
      enabled: true
      base_url: https://skills.sh
      search_url: "https://skills.sh/?q={query}"
      install_url: ""
      trust_level: high
```

- `skills.catalogs`：外部 skill 源声明列表。
- `skills.catalogs[].name`：skill 源名称。
- `skills.catalogs[].enabled`：是否启用这个源。
- `skills.catalogs[].base_url`：源站根地址。
- `skills.catalogs[].search_url`：搜索 URL 模板，`{query}` 会被替换为查询词。
- `skills.catalogs[].install_url`：安装 URL 模板。为空表示当前不声明自动安装入口。
- `skills.catalogs[].trust_level`：信任级别，如 `high`、`medium`、`unknown`。

注意：当前 catalog 主要是搜索/展示入口声明，不代表每个源都能自动安装。不同源后续需要 adapter 来定义 search/resolve/install 过程。

### `scheduler`

```yaml
scheduler:
  enabled: false
  timezone: Asia/Shanghai
  state_dir: ""
  interval: 30s
```

- `scheduler.enabled`：是否默认启用调度 runner。CLI 仍可手动执行 schedule 命令。
- `scheduler.timezone`：定时任务默认时区。
- `scheduler.state_dir`：调度状态目录。留空时使用 `<home>/schedules`。
- `scheduler.interval`：`schedule serve` 检查到期任务的间隔。

定时任务是 channel-neutral：scheduler 只负责保存、试跑、到点执行和记录 run record，不内置飞书/邮件/Slack 投递。

### `agents`

```yaml
agents:
  default: main
  profiles:
    - id: main
      name: Main Assistant
      default: true
      session_namespace: main
      model:
        default: minimax
        fallbacks: []
      heartbeat:
        enabled: false
        interval: 30m
        schedule:
          daily_at: "03:30"
        jobs:
          - memory_lint
          - memory_index_rebuild
        auto_send_summary: false
        quiet_hours:
          start: "23:00"
          end: "08:00"
      skills:
        allow: []
        deny: []
      tools:
        allow: []
        deny: []
  bindings:
    - channel: cli
      agent_id: main
    - channel: feishu
      agent_id: main
```

- `agents.default`：默认 agent id。没有匹配 binding 时使用它。
- `agents.profiles[]`：agent profile 列表。
- `agents.profiles[].id`：agent 唯一标识，对应 `workspace/agents/<agent_id>/`。
- `agents.profiles[].name`：显示名称。
- `agents.profiles[].default`：是否标记为默认 profile。
- `agents.profiles[].workspace_root`：该 agent 的工作区根目录。为空时使用全局 workspace。
- `agents.profiles[].agent_dir`：该 agent 的 profile 文件目录。为空时按 `workspace/agents/<agent_id>` 推导。
- `agents.profiles[].session_namespace`：session 命名空间，用于隔离不同 agent 的会话语义。
- `agents.profiles[].model`：该 agent 的模型配置，可覆盖全局 `model`。
- `agents.profiles[].heartbeat.enabled`：是否启用该 agent 的 heartbeat。
- `agents.profiles[].heartbeat.interval`：heartbeat 间隔。
- `agents.profiles[].heartbeat.schedule.daily_at`：每日固定 heartbeat 时间。
- `agents.profiles[].heartbeat.jobs`：heartbeat 任务列表，例如 `memory_lint`、`memory_index_rebuild`。
- `agents.profiles[].heartbeat.auto_send_summary`：是否自动发送摘要。当前建议保持关闭，通知应由任务脚本/skill/connector 完成。
- `agents.profiles[].heartbeat.quiet_hours.start/end`：安静时段。
- `agents.profiles[].skills.allow/deny`：该 agent 允许或拒绝的 skill 名称列表，当前作为产品化预留。
- `agents.profiles[].tools.allow/deny`：该 agent 允许或拒绝的 tool 名称列表，当前作为产品化预留。
- `agents.profiles[].metadata`：可选元数据，结构是字符串键值对。
- `agents.bindings[]`：channel/account/peer 到 agent 的绑定规则。
- `agents.bindings[].channel`：channel 名称，如 `cli`、`feishu`。
- `agents.bindings[].account_id`：可选账号维度。为空表示不按账号限制。
- `agents.bindings[].peer_id`：可选会话/群/联系人维度。为空表示不按 peer 限制。
- `agents.bindings[].agent_id`：绑定到的 agent id。

当前多 agent 是 profile/binding/context 隔离，不是 supervisor/subagent/DAG 编排。

### `security`

```yaml
security:
  enforce_workspace_paths: true
  require_approval_for_risky_tools: true
  accessible_paths: []
  terminal_sandbox:
    enabled: false
    mode: restricted
    workdir: ""
    timeout_seconds: 20
    command_prefix: []
```

- `security.enforce_workspace_paths`：是否限制文件工具只能访问项目根、workspace 和 `accessible_paths`。
- `security.require_approval_for_risky_tools`：高风险工具是否需要用户确认。
- `security.accessible_paths`：额外允许访问的本机路径列表。
- `security.terminal_sandbox.enabled`：是否启用 terminal sandbox wrapper。
- `security.terminal_sandbox.mode`：sandbox 模式名称，当前主要用于报告和后续 runner 产品化。
- `security.terminal_sandbox.workdir`：terminal 默认工作目录。
- `security.terminal_sandbox.timeout_seconds`：terminal 命令超时时间。
- `security.terminal_sandbox.command_prefix`：执行 terminal 命令前追加的 wrapper/prefix，例如 sandbox 命令前缀。

### `search`

```yaml
search:
  default_tool: tavily
  provider_order: [tavily, searxng, duckduckgo]
  cache_enabled: true
  cache_ttl_hours: 168
  fresh_cache_ttl_hours: 6
  providers:
    tavily:
      enabled: false
      base_url: https://api.tavily.com/search
      api_key_env: TAVILY_API_KEY
      timeout_seconds: 8
      max_results: 5
      daily_budget: 20
      monthly_budget: 900
      search_depth: basic
      topic: general
    searxng:
      enabled: false
      base_url: http://127.0.0.1:8088
      timeout_seconds: 8
      max_results: 5
    duckduckgo:
      enabled: true
      timeout_seconds: 4
      max_results: 5
      region: cn-zh
```

- `search.default_tool`：默认搜索工具/提供方名称。
- `search.provider_order`：搜索 provider 尝试顺序。
- `search.cache_enabled`：是否启用搜索缓存。
- `search.cache_ttl_hours`：普通搜索缓存有效小时数。
- `search.fresh_cache_ttl_hours`：实时/新鲜信息搜索缓存有效小时数。
- `search.providers.<name>.enabled`：是否启用某个 provider。
- `search.providers.<name>.base_url`：provider API 或服务地址。
- `search.providers.<name>.api_key`：直接写入的 API key，不推荐。
- `search.providers.<name>.api_key_env`：从环境变量读取 API key，推荐。
- `search.providers.<name>.timeout_seconds`：请求超时时间。
- `search.providers.<name>.max_results`：最大结果数量。
- `search.providers.tavily.daily_budget`：Tavily 每日预算。
- `search.providers.tavily.monthly_budget`：Tavily 每月预算。
- `search.providers.tavily.search_depth`：Tavily 搜索深度。
- `search.providers.tavily.topic`：Tavily 搜索主题。
- `search.providers.<name>.include_domains`：可选域名白名单。
- `search.providers.<name>.exclude_domains`：可选域名黑名单。
- `search.providers.duckduckgo.region`：DuckDuckGo 区域参数。

## `models/*.yaml`

模型配置示例：

```yaml
name: minimax
provider: minimax
api: anthropic
model: MiniMax-M2.7
api_base: https://api.minimaxi.com/anthropic
api_key: ""
api_key_env: MINIMAX_API_KEY
strip_reasoning: true
enabled: true
description: Default remote model for planning, repair, synthesis, and high-reliability tasks.
```

- `name`：模型配置名，供 `model.default` 或 agent profile 引用。
- `provider`：模型供应商标识。
- `api`：API 兼容类型，如 `anthropic`、`openai`。
- `model`：供应商侧模型名。
- `api_base`：API base URL。
- `api_key`：直接写入的 API key，不推荐。
- `api_key_env`：读取 API key 的环境变量名，推荐。
- `strip_reasoning`：是否剥离 reasoning 内容，避免把模型内部推理暴露给用户。
- `enabled`：是否启用该模型配置。
- `description`：模型用途说明。

## `channels/feishu.yaml`

```yaml
feishu:
  enabled: false
  app_id: ""
  app_id_env: MATEWAY_FEISHU_APP_ID
  app_secret: ""
  app_secret_env: MATEWAY_FEISHU_APP_SECRET
  verification_token: ""
  verification_token_env: MATEWAY_FEISHU_VERIFICATION_TOKEN
  encrypt_key: ""
  encrypt_key_env: MATEWAY_FEISHU_ENCRYPT_KEY
  base_url: https://open.feishu.cn
  bot_name: mateway
  auto_reply: true
  mention_required_in_group: true
  webhook:
    enabled: false
    addr: 127.0.0.1:8788
    path: /feishu/events
  websocket:
    enabled: true
```

- `feishu.enabled`：是否启用飞书 channel。
- `feishu.app_id`：飞书应用 App ID。建议留空，用 `app_id_env`。
- `feishu.app_id_env`：读取 App ID 的环境变量名。
- `feishu.app_secret`：飞书应用 App Secret。建议留空，用 `app_secret_env`。
- `feishu.app_secret_env`：读取 App Secret 的环境变量名。
- `feishu.verification_token`：飞书事件订阅 verification token。建议通过环境变量提供。
- `feishu.verification_token_env`：读取 verification token 的环境变量名。
- `feishu.encrypt_key`：飞书事件加密 key。建议通过环境变量提供。
- `feishu.encrypt_key_env`：读取 encrypt key 的环境变量名。
- `feishu.base_url`：飞书 OpenAPI 地址。
- `feishu.bot_name`：机器人名称。
- `feishu.auto_reply`：是否自动回复收到的消息。
- `feishu.mention_required_in_group`：群聊中是否要求 @ 机器人后才处理。
- `feishu.webhook.enabled`：是否启用 webhook 模式。
- `feishu.webhook.addr`：webhook 监听地址。
- `feishu.webhook.path`：webhook 路径。
- `feishu.websocket.enabled`：是否启用 WebSocket 模式。

## `mateway.env`

`mateway.env` 示例：

```env
MINIMAX_API_KEY=
OPENAI_API_KEY=
TAVILY_API_KEY=

MATEWAY_FEISHU_APP_ID=
MATEWAY_FEISHU_APP_SECRET=
MATEWAY_FEISHU_VERIFICATION_TOKEN=
MATEWAY_FEISHU_ENCRYPT_KEY=
```

- `MINIMAX_API_KEY`：MiniMax API key。
- `OPENAI_API_KEY`：OpenAI API key。
- `TAVILY_API_KEY`：Tavily 搜索 API key。
- `MATEWAY_FEISHU_APP_ID`：飞书应用 App ID。
- `MATEWAY_FEISHU_APP_SECRET`：飞书应用 App Secret。
- `MATEWAY_FEISHU_VERIFICATION_TOKEN`：飞书事件 verification token。
- `MATEWAY_FEISHU_ENCRYPT_KEY`：飞书事件 encrypt key。

`mateway.env` 是本机私密文件，不应提交到 Git。配置文件里的 `*_env` 字段会读取这些环境变量。

## Secret Store

Mateway 也提供跨平台本地 secret store，用于 skill、脚本和未来 Script Bridge 引用凭证，而不是把用户名、密码、token 写进 `SKILL.md`。

```bash
mateway secret set mail.smtp_user "alice@example.com"
mateway secret set mail.smtp_pass
mateway secret list
mateway secret get mail.smtp_pass
mateway secret delete mail.smtp_pass
```

存储位置：

```text
~/.mateway/secrets/secrets.json
```

说明：

- `mateway secret set <id> [value]`：保存 secret。省略 value 时从 stdin 读取。
- `mateway secret list`：只列出 secret id 和更新时间，不显示值。
- `mateway secret get <id>`：输出 secret 值，主要供脚本或后续 Script Bridge 使用。
- `mateway secret delete <id>`：删除 secret。
- `secrets.json` 文件权限为 `0600`，目录权限为 `0700`。
- 当前实现不依赖 macOS Keychain、Linux Secret Service 或 Windows Credential Manager，避免平台绑定。

Skill 应声明 secret 引用，而不是写明文：

```yaml
---
name: mail-send
required_secrets:
  - id: mail.smtp_user
    env: SMTP_USER
  - id: mail.smtp_pass
    env: SMTP_PASS
---
```

Skill 正文可以写“使用 `mail.smtp_pass` 对应的 secret”，不能写 `password: xxx`、`smtp_pass: xxx`、`token: xxx` 这类明文字段。`mateway skill install` 和写入 `SKILL.md` 的 `file.write` 会扫描 secret-like 内容并拒绝写入。
