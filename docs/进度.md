## 当前问题

- 真实任务耗时需要继续观察，主要耗时在模型侧。
- init 已种下少量默认 shared skills；已有 HOME 不会被 init 覆盖，后续如需同步默认 skill，需要单独设计 sync 命令。
- 两个 `memory.md` 已明确分工：`workspace/agents/main/memory.md` 是 prompt-facing 短摘要，`workspace/memory/agents/main/memory.md` 是长期记忆 wiki 入口。
- 邮件、远程服务器运维、自媒体发布仍没有完整 connector framework；当前策略是先探测本机能力、已有 CLI/配置、脚本/API 方案，不能编造完成。
- 当前没有 `~/.mateway/logs` 文件日志；可观察性依赖 trace JSONL，launchd 承接 gateway stdout/stderr。
- 当前没有 OS-level sandbox；只有 workspace path policy、危险命令确认、terminal sandbox wrapper 配置和文件大小/binary guard。
